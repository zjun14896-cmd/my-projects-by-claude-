02/上手

听懂了，
可一上手就卡住？

这是最常见的问题，也是课堂上最花时间的地方。

讲完，就动手。电脑打开，手机拿出来，在自己的设备上，把刚才那一步完整走一遍。

卡住的地方，正是老师要过来的地方。

03/带教

现场，
到底怎么带？

不是一个人站在台上讲到底。

老师会坐到你对面，凑过来看你的手机屏幕，在灯前和你当面聊。同一个问题，换一种说法再讲；同一个操作，看着你做完。

左右滑动

围桌

面对面，把问题摊开说。

手机前

看着你的屏幕，指出卡在哪。

灯前

在现场，当面讲清楚。

讲的东西，
能落到具体产品上吗？

课堂上讲的每一个方法，最后都要回到一件具体的商品上。

比如这一页。屏幕上放的是一台风扇，问题只有一个。

这就是落地。

效果与验证

版式：字号层级、留白、圆角照片、深色模块本地已演示纯内联样式，公众号正常保留。深色模块的底色画在 SVG 里，不受公众号深色模式改色影响。
开头：五天进度线依次点亮SMIL 自动播放加载即播放，位于首屏。
开关：听懂 → 做到SMIL begin=click热区放在最深层，点击冒泡驱动三层动画；不依赖 id。
照片热点注释（2 处）SVG 叠在图片上用负 margin 叠放，不用绝对定位；热点外的区域仍可点开大图。
横滑相册overflow-x 滚动纯 HTML，无脚本。
一道题：四问依次浮现SMIL 级联静态兜底：动画被过滤时直接显示四个问题。
自测清单：轻点打勾SMIL 描边动画每行独立。
粘贴后结构与交互是否保留需真机验证重点：负 margin 叠放是否对齐、点击是否触发、安卓是否同样生效、深色模式观感。
图片自动转存需后台验证取决于公众号能否拉取图片地址；失败时用「替换图片」，或用 API 脚本上传。

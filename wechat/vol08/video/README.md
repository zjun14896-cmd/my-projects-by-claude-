## 结构（120 BPM，一小节 2 秒，共 9 小节）
| 时间 | 画面 | 声音 |
|---|---|---|
| 0–2s | 亮色背景上，四千多颗粒子旋转汇聚成「08」，然后填色，一道光线划过 | Fmaj9 铺底渐强、高音闪烁、噪声上扬 |
| 2s | 中心炫光爆开，粒子四散 | 重拍、冲击音 |
| 2–4s | 五段视频在 3D 倾斜的拼贴墙上同时播放，依次弹入，带高光扫过；镜头随后推进主画面 | 琶音、半拍鼓、滚奏 |
| 4–14s | 五段现场各 2 秒，毛玻璃字幕卡：LEARN / PRACTICE / ONE ON ONE / CREATE / AI | 完整节奏，和弦 F C Dm Bb C |
| 切换点 | 6s 横扫炫光，8s 中心爆闪加火花，10s 斜向光斑扫过，12s 反向棱镜炫光；每次都带白闪和色散 | 每次切换前「唰」，切点上有冲击音 |
| 14–16.6s | 镜头拉回拼贴墙，五段同时播放；随后每块画面边缘燃起金色光边，化为粒子飘散 | 鼓组退出，Bb → C 铺底，上扬 |
| 16–18s | 落款：五天，把路走通。/ 第 9 期 · 招生中 / logo，一道光线划过 | F(add9) 大和弦、亮音 |

## 制作流程（全部为代码，可复现）
1. 素材：iPhone HLG HDR 原片，用 ffmpeg zscale + hable 色调映射转为 BT.709 SDR。
2. `music.py`：用 numpy/scipy 合成配乐，没有用任何采样或版权素材。
3. `overlay.html` + `render.js`：用 Chromium 逐帧渲染文字、毛玻璃卡片描边、毛玻璃遮罩和「08」字形遮罩。字体为 Inter 与思源黑体，都是开源可商用字体。
4. `compose.py`：用 OpenCV/numpy 逐帧合成，包括粒子系统（汇聚、爆散、燃烧飘散、浮尘）、3D 透视拼贴墙（相机推拉、投影、圆角）、程序化镜头炫光（光条、星芒、鬼影）、光斑、色散、毛玻璃、明亮调色和柔光。所有动画都是时间的函数，可以 4 进程并行渲染。

```bash
python3 music.py music.wav
node render.js frames/ fonts.css all
python3 -I compose.py sdr/ frames/ music.wav out/vol08-18s-1080p.mp4 --workers 4
```

## 版式规则
- **全文居中**。长段落手动断成长短均匀的短行，每行约 17 字以内，避免最后一个字单独掉到下一行。插画小卡片内部是左图右文，所以卡片里的文字左对齐。
- **插画**：六个小插画都是内联 SVG，白色圆底配品牌蓝黄线条，各带一个很轻的循环动效，用来缓和营销感，让读者一眼看到重点。
- **章节开头**：细体大序号（`01 / 05`）加一行读者的原话，原话就是标题。
- **加粗**：每节以「所以……」开头的回答句加粗；荧光笔每节最多一处。
- **配色**：品牌蓝负责结构，品牌黄负责强调；白底长文，中间穿插深色和品牌蓝的模块。

### 关于翻面卡（上一版点了没反应的问题）
旧结构要点击事件穿过多层组、靠继承属性和 `<set>` 初始化才能生效，在部分环境里不触发。新结构只有一层：透明点击区和翻面动画在同一个 `<g>` 里，背面始终画在底下，正面收拢后自然露出来。整个结构不用 `pointer-events`、`<set>`，也不靠继承属性。本地 Chromium 里，手机触摸轻点和电脑鼠标点击都验证过。

## 发布流程
1. 用电脑版 Chrome 或 Edge 打开 `preview.html` 或在线预览页。
2. 公众号后台 → 新的创作 → 文章，填入标题和摘要。
3. 点 **复制正文**，到编辑器的正文区粘贴，等图片转存完成。
4. **插入短片**：开头深色卡片底部有一个虚线框「在此处插入视频」，把光标放进框里 → 工具栏「视频」→ 上传 `video/out/vol08-18s-1080p.mp4`。插入后删掉虚线框。
5. 封面上传 `cover/cover-235.jpg`，1:1 的裁切用 `cover-1x1.jpg`。
6. 保存草稿 → 预览 → 发送到手机，按上面的清单验证，都通过后再群发。

> 图片如果大面积转存失败，在发布台里把图片地址切换成「GitHub Raw」再复制一次；个别破图可以点那张图 → 替换 → 从 `img/` 里选同名文件。

## 修改文案
- **普通段落**：粘贴进公众号后，直接在编辑器里改。
- **SVG 模块里的文字**（翻面卡、节奏环、流程、五天之后）：编辑 `build.py`，运行 `python3 build.py`，然后重新复制。

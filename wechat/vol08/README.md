## 设计系统

- **配色**：白底长文，加午夜蓝 `#050A18` 的模块。品牌蓝 `#003CAC` 负责结构，包括序号、标签和图形；品牌黄 `#FFC833` 只用来强调，包括荧光笔、进度和亮点。
- **章节开头**：细体大序号（`01 / 05`），下面是读者原话做标题，用蓝色「」括起来。标题本身就是读者的疑问。
- **加粗规则**：每节里「所以……」开头的那句是我们的回答，统一加粗。荧光笔每节最多一处，标出这一节最想让读者记住的事实。
- **断行**：短句和大字句都手动断行，避免一个字单独掉到下一行。长段落让它自然换行。
- **字体**：系统字体，在 iPhone 上是苹方。序号用细体，标题和强调用粗体。

## 三类效果，分开说明

### 已在本地浏览器演示（Chromium，375px 宽手机，正文 343px）
- 全部版式，页面没有横向溢出。
- 开头「08」的动画、节奏环、五天之后的虚线流动。
- 三张情况卡和流程模块：逐个点过，点击前后都截图核对。

### 准备采用的公众号实现方式
- **只用内联样式**，不用 `<style>`、`<script>`、`class`、`id`、`position:absolute`。`build.py` 每次构建都会检查，出现这些写法就直接报错。
- **交互用 SVG + SMIL**，触发方式是 `begin="click"`。公众号会删掉 `id`，所以不能跨元素触发。这里的做法是：把透明点击区放在最深一层，点击事件向上冒泡，经过的每一层 `<g>` 各自播放一段动画。
- **静态兜底**：如果 SMIL 被过滤，情况卡直接显示答案，流程六步全部点亮，「08」直接显示为白色实心。
- **浅色模块的底色画在 SVG 里**，所以微信深色模式不会把它们变暗、导致文字看不清。
- **荧光笔和深色模块的柔光**用 CSS 渐变。如果被过滤，荧光笔只剩加粗，柔光退回纯色底。

## 发布流程

### 方式 A：复制粘贴
1. 用电脑版 Chrome 或 Edge 打开 `preview.html`（或在线预览页）。
2. 公众号后台 → 新的创作 → 文章，填入标题和摘要。
3. 点 **复制正文**，到编辑器的正文区粘贴。
4. 等图片转存完成。如果有破图，点那张图 → 替换 → 从 `img/` 里选同名文件。
5. 封面上传 `cover/cover-235.jpg`，1:1 的裁切用 `cover-1x1.jpg`。
6. 保存草稿 → 预览 → 发送到手机，按上面的清单验证，都通过后再群发。

> 如果图片大面积转存失败，在发布台里把图片地址切换成「GitHub Raw」再复制一次。

### 方式 B：接口直接生成草稿（需要公众号已认证，并把电脑 IP 加进白名单）
```bash
export WX_APPID=wx...  WX_SECRET=...
python3 publish_draft.py --dry-run
python3 publish_draft.py
```
这个脚本没有在真实公众号上跑过，第一次运行时请留意它打印出来的报错。

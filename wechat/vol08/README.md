## 文章结构

整篇以读者报名前的五个疑问为线索，每个疑问用课堂照片回答：

1. **开头**：深色卡片，五天进度线依次点亮，配课堂主图。
2. **开关交互**：「听懂了。」→「做出来了。」。这个开关就是全文的主题。
3. **01 起点**：基础不好，跟得上吗？屏幕演示照片，加一张白板照片（带热点注释）。
4. **02 上手**：听懂了，可一上手就卡住？学员实操照片（带热点注释）。
5. **大字句**：讲完就做，做完再讲。
6. **03 带教**：现场到底怎么带？横滑相册三张：围桌、手机前、灯前。
7. **04 落地**：讲的东西能落到具体产品上吗？先放课堂屏幕局部，再放「一道题」卡片，点一下依次出现四个问题。卡片里的文字全部取自课堂屏幕。
8. **05 判断**：这种方式适合我吗？四句话的自测清单，点一下打勾。
9. **结尾**：深色卡片，交代品牌，加留言引导。

配色取自 logo：品牌蓝 `#003CAC`、品牌黄 `#FFC833`，配合接近黑色的 `#07090F`，以及苹果式的灰阶。正文用系统字体，在 iPhone 上就是苹方。正文里的文字都可以在公众号编辑器里直接改；交互模块里的文字是 SVG，要在 `build.py` 里改。

## 三类效果，分开说明

### 已在本地浏览器演示（Chromium，375px 宽）
- 全部版式：字号层级、留白、圆角照片、深色模块、横滑相册。页面没有横向溢出。
- 开头进度线的自动动画。
- 开关、两个照片热点、一道题、自测清单：逐个点过，点击前后都截图核对过。

### 准备采用的公众号实现方式
- **只用内联样式**，不用 `<style>`、`<script>`、`class`、`id`、`position:absolute`。`build.py` 每次构建都会检查，出现这些写法就直接报错。
- **交互全部用 SVG + SMIL**（`<animate>`、`<set>`、`<animateTransform>`），触发方式是 `begin="click"`。公众号会删掉 `id`，所以不能用 `xx.click` 跨元素触发。这里的做法是：把透明点击区放在最深一层，点击事件向上冒泡，经过的每一层 `<g>` 各自播放一段动画。
- **照片上的热点**：用负 `margin-top` 把 SVG 叠到 `<img>` 上，不用绝对定位。叠层设了 `pointer-events:none`，所以点热点以外的地方，照片仍能点开看大图。
- **静态兜底**：如果 SMIL 被过滤，各模块停在可以正常阅读的完成态：开关显示「做出来了。」，四个问题直接显示，热点注释直接显示。只有自测清单停在未勾选状态。
- **深色模块的柔光**用 CSS `radial-gradient`。如果被过滤，就退回纯深色底。
- **图片**：粘贴后公众号会把外链图片自动转存到自己的服务器。另一种方式是用 API 先上传，拿到 `mmbiz` 地址再写进正文。

### 还需要导入编辑器、保存草稿、在微信里真机验证
- [ ] 粘贴后，五个交互模块是否完整保留（在编辑器里看是否能显示）
- [ ] 保存草稿 → 预览 → 发送到手机，在 **iPhone** 上逐个点：开关、两个热点、一道题、四个勾
- [ ] 在 **安卓** 上重复一遍
- [ ] 两张热点照片上的叠层是否和照片对齐（主要看负 margin 是否被保留）
- [ ] 横滑相册能否左右滑动
- [ ] 打开微信的 **深色模式** 再看一遍：深色模块应该不变，白底部分会被微信自动转成深色
- [ ] 图片是否全部转存成功（没有破图）
- [ ] 进度线的动画在打开文章时会播放一次

真机上如果某个交互不生效，先截图告诉我是哪一个。正文结构不用变，换掉那个模块的实现方式即可。

## 发布流程

### 方式 A：复制粘贴（推荐先试这个）
1. 用电脑版 Chrome 或 Edge 打开 `preview.html`。也可以从仓库下载 `wechat/vol08` 整个文件夹到本地再打开。
2. 公众号后台 → 新的创作 → 文章。标题和摘要用上面给的。
3. 在 `preview.html` 里点 **复制正文**，到编辑器的正文区粘贴。
4. 等图片转存完成。如果有破图，点那张图 → 替换 → 从 `img/` 里选同名文件。
5. 封面上传 `cover/cover-235.jpg`，1:1 的裁切用 `cover-1x1.jpg`，或者在编辑器里直接裁。
6. 保存草稿 → 预览 → 发送到手机，按上面的清单验证。
7. 验证都通过后再群发。

> 图片地址默认用 jsDelivr CDN。如果粘贴后图片大面积转存失败，在发布台里把图片地址切换成「GitHub Raw」再复制一次。也可以填你们自己的图床前缀（先把 `img/` 里的文件传上去）。

### 方式 B：接口直接生成草稿（需要公众号已认证）
```bash
export WX_APPID=wx...  WX_SECRET=...
python3 publish_draft.py --dry-run   # 先检查文件
python3 publish_draft.py             # 上传图片和封面，生成草稿
```
需要先在公众号后台 → 设置与开发 → 基本配置，把运行脚本那台电脑的 IP 加进白名单。这个脚本没有在真实公众号上跑过，第一次运行时请留意它打印出来的报错。

## 修改文案

- **只改正文段落**：粘贴进公众号后，直接在编辑器里改。
- **改交互模块里的文字**（开关、一道题、自测清单、热点注释）或者改结构：编辑 `build.py` 里的 `article()` 函数，运行 `python3 build.py`，然后重新复制。
- **做下一期**：复制整个 `vol08` 文件夹，替换照片和文案，把 VOL 编号改掉即可。整个版式本身就是按系列设计的。

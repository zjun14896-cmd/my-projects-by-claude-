# 口语精听校对（speaking-coach）

每天用手机随便讲一段英文，不看稿，上传到电脑后：

1. **转写**：把录音变成逐句英文，尽量保留原话，说错的词和语法也照样保留
2. **精听校对**：每句可以单独播放，你逐字改成自己**实际说的**内容
3. **对照 AI 的理解**：旁边是 AI 根据你的英文理解出来的中文。意思对就点 ✓；不对就点 ✗，写下「我其实想说……」
4. **生成更地道的说法**：每句右边给出更自然的英文，并逐条指出问题：「你说的 → 更好的说法：原因」

所有内容都在同一行左右对照，不用上下翻页。

---

## 第一次使用（Windows）

1. 在 GitHub 页面点 **Code → Download ZIP**，解压到一个好找的位置，例如 `D:\speaking-coach`
2. 进入 `speaking-coach` 文件夹，**双击 `start.bat`**
   - 会弹出一个黑色窗口（这就是程序本身，**用的时候不要关**）
   - 浏览器会自动打开 <http://127.0.0.1:8765>
3. 如果黑色窗口提示找不到 python：到 <https://www.python.org/downloads/> 安装 Python，安装时**勾选 "Add python.exe to PATH"**

不需要 `pip install` 任何东西，程序只用 Python 自带的功能。
请用 **Edge 或 Chrome** 打开页面，它们能直接读取手机录音的 m4a 格式。

想退出时，关掉黑色窗口就可以。

## 每天的流程

1. 首页把录音拖进去（m4a / mp3 / wav / mp4 都可以）
2. 选择转写方式：
   - **豆包自动转写**：需要先在「设置」里填好豆包密钥
   - **按停顿自动切段，自己听写**：不需要任何密钥，程序按你说话的停顿把录音切成小段，你边听边写
   - **粘贴已有英文文本**：用别的工具转写过的话，直接粘贴进来
3. 逐句校对英文，看中间一栏 AI 的理解，标记 ✓ 或 ✗
4. 点上方「③ 生成更地道的说法」
5. 想留着复习的话，可以「导出 Markdown」

### 小技巧

- 光标在英文框里时，按 <kbd>Esc</kbd> 播放 / 暂停这一句，按 <kbd>Tab</kbd> 跳到下一句
- 改完一句英文，光标离开后，AI 会按新的英文自动重新理解这一句
- 播放器旁边可以调慢速度（0.6× / 0.75×），听不清时很有用
- 切句不对时，可以用每句下面的「✂ 拆分」（在光标处拆开）或「⤓ 合并下一句」
- 「🔊 朗读」会用电脑的英文语音读出地道版本。Edge 自带的英文语音比较自然
- 所有修改都会自动保存

## 配置密钥（右上角「设置」）

密钥只保存在这台电脑的 `data/settings.json` 里。页面上只显示末尾 4 位，不会显示完整内容。

### DeepSeek（AI 理解 + 地道说法）

1. 打开 <https://platform.deepseek.com>，注册并充值（很便宜，练一天大概几分钱）
2. 左侧「API keys」→ 创建 → 复制 `sk-` 开头的密钥
3. 粘贴到「设置 → DeepSeek → API Key」，点「保存并测试」

### 豆包语音（转写）—— 接口写好了，还没用真实密钥测过

用的是火山引擎的「**大模型录音文件识别 · 极速版**」（Resource ID：`volc.bigasr.auc_turbo`）。这个接口可以直接上传音频，几秒钟出结果，每句都带时间。

1. 登录火山引擎控制台 → 豆包语音 → 开通「录音文件识别大模型 极速版」
2. 拿到密钥，**二选一**填写：
   - 新版控制台：**API Key**
   - 旧版控制台：**App ID + Access Token**
3. 填到「设置 → 豆包语音」，点「保存并测试」（程序会发一秒静音过去，验证密钥能不能用）

转写时已经关掉了「语义顺滑」（`enable_ddc: false`），尽量保留重复、口误等原话。
如果测试失败，把报错截图发过来，再一起调。

## 数据在哪里

- 所有录音和校对记录都在 `speaking-coach/data/` 文件夹里
- 备份：复制整个 `data` 文件夹
- 更新程序：用新版本的文件覆盖时，**保留 `data` 文件夹**
- `data/` 已经写进 `.gitignore`，不会被提交到 GitHub

## 常见问题

| 问题 | 解决 |
|---|---|
| 「浏览器无法解码这个音频格式」 | 换用 Edge / Chrome；或者先把录音转成 mp3 再上传 |
| 「端口 8765 被其他程序占用」 | 可能是程序已经开着了，直接打开 <http://127.0.0.1:8765>；或者在文件夹里运行 `set PORT=8766 && python server.py` |
| 「连不上本地程序」 | 黑色窗口被关了，重新双击 `start.bat` |
| AI 返回出错 | 看提示：401 = 密钥不对，402 = 余额不足；其他错误可以点「重试」 |

## 文件结构（给以后改代码用）

```
speaking-coach/
├── start.bat      双击启动
├── server.py      本地服务器：网页、练习记录、设置（Python 标准库）
├── services.py    所有外部 AI 调用都在这里：豆包转写、DeepSeek 提示词
└── web/           页面（原生 HTML/CSS/JS，不需要编译）
    ├── index.html
    ├── style.css
    └── app.js
```

- 想换语音识别服务：只改 `services.py` 里的 `doubao_transcribe()`，返回 `[{start, end, text}]` 就行
- 想调整 AI 的说话风格：改 `services.py` 里的 `UNDERSTAND_SYSTEM` 和 `IMPROVE_SYSTEM` 两段提示词

第一版刻意没做：本地 Whisper 大模型、手机 App、账号系统、练习出题。
